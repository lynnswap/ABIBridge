# ``ABIBridge``

Resolve native declarations and call or intercept native code on Apple platforms.

## Overview

Use ABIBridge to locate C, C++, and Swift symbols by source-level name, invoke supported functions and methods with Swift types and values, and manage native values and call hooks. Resolved symbols and prepared call handles retain their implementation images.

The Swift API requires Swift 6.3 or later and supports iOS 18.4, macOS 15.4, visionOS 2.4, watchOS 11.4, and tvOS 18.4 or later.

Start with <doc:SymbolsAndImages> to find a declaration, or choose a language below to prepare a call. Each collection groups its usage guides and API reference.
